# VBA_Tools

*A collection of Excel VBA macros for everyday office work: merging workbooks, listing files, extracting text, and auditing VBA code.*

Excel業務を効率化するVBAマクロ集です。
ファイル管理・コード監査・テキスト抽出・書式設定など、実務で役立つツールを収録しています。

専門用語を使わない説明は [説明書.md](説明書.md) にあります。

## ツール一覧

### ファイル管理系

| ツール | 説明 |
|--------|------|
| **Excelファイルを結合.bas** | 複数フォルダのExcelファイルを再帰的に探索し、指定シートのデータを1つのブックに統合します |
| **フォルダ階層ファイル一覧作成.bas** | 指定フォルダ配下のファイルを階層的に一覧化し、種類別（Excel/テキスト/CSV）に分類します |
| **ファイルパス分解処理.bas** | ファイルパスをファイル名・拡張子・各階層フォルダに分解し、ハイパーリンク付きで出力します |
| **ファイル最終更新日取得.bas** | A列のファイルパスから各ファイルの最終更新日時を取得してB列に出力します |

### VBAコード監査系

| ツール | 説明 |
|--------|------|
| **全量取得_コード_シートパス.bas** | シートに記載された.basファイルパスからVBAコードを全行抽出し、Sub/Function名やメタ情報付きで出力します |
| **全量取得_コード_フォルダ指定.bas** | フォルダパスを指定して、その直下の.basファイルからコードを一括抽出します |
| **マクロキー情報取得.bas** | ブック内の全VBAモジュールからショートカットキーの割り当て情報を抽出・一覧化します |

### テキスト抽出系

| ツール | 説明 |
|--------|------|
| **エクセルテキスト取得.bas** | Excel（.xls/.xlsx/.xlsm）およびPowerPoint（.pptx）ファイルからテキストを抽出します |

### 書式・編集系

| ツール | 説明 |
|--------|------|
| **特定文字色変更.bas** | セル内の特定文字列に対して色やボールドを適用します（部分一致対応） |
| **色_文字列.bas** | 特定文字色変更と同様の機能を2つのSubに分離した構成です |
| **拡大率変更.bas** | ブック内の全シートの表示倍率を一括変更します（デフォルト80%） |
| **列指定下埋.bas** | 指定列の空白セルを直上の値で下方向に埋めます（結合セル解除後の補完に便利） |
| **目次作成_相対パス.bas** | ブック内の全シートへのハイパーリンク付き目次（INDEX）シートを自動作成します |
| **業務効率化マクロ集.bas** | 行・列の挿入/削除、高さ・幅の自動調整、改行・スペース除去など10種の小型ユーティリティ集 |

## 使い方

1. 使いたい `.bas` ファイルをダウンロード
2. Excelで VBE（Alt + F11）を開く
3. 「ファイル」→「ファイルのインポート」で `.bas` ファイルを読み込む
4. マクロを実行（Alt + F8）

## 注意事項

### 文字コードについて

本リポジトリの `.bas` ファイルは UTF-8 で保存しています。
VBE のインポートは ANSI（日本語環境では Shift_JIS）を前提とするため、そのまま取り込むと日本語のモジュール名・Sub名・コメントが文字化けする場合があります。
文字化けする場合は、テキストエディタで `.bas` を Shift_JIS（ANSI）に変換して保存し直してから、VBE にインポートしてください。

### マクロキー情報取得.bas の副作用と前提

- 実行中に、ブックと同じフォルダへ一時ファイル `Temp1.bas` を書き出し、処理後に削除します（同名ファイルがある場合は上書きにご注意ください）。
- Excel のトラスト センターで「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」を有効にしておく必要があります。

## 動作環境

- Microsoft Excel（Windows）
- VBA 7.0以上推奨
